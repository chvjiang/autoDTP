# autoDTP
Considering the key factor of the security of pedestrians in autonomous driving transportation, we provide a comprehensive dataset focusing on pedestrian detection, tracking and prediction based on the NuScenes Dataset. We also propose a useful pipeline for pedestrian alerts designed for autonomous driving systems.
## Quick Start
To utilize our dataset, you should setup your python environment as following.
```
conda create -n autodtp python=3.9
conda activate autodtp
pip install nuscenes-devkit ultralytics
```
